# Joyboy

Ink TUI client scaffold for AllAnime/AllManga persisted-query API.

## Run

```bash
npm install
npm run dev
```

## Environment

- `ANIME_PLAYER` (default: `mpv`)
- `ANIME_PLAYER_ARGS` (space-delimited additional args)

## Current status

- API persisted query client with required headers
- Search service and cover URL normalization
- Ink search/results/detail navigation shell
- External player launcher adapter
